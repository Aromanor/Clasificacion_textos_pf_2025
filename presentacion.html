Resumen del Jupyter Book

En la rama gh-pages de este repositorio se encuentra publicado un libro generado con Jupyter Book. A continuación se listan las secciones principales:

  • Introducción
  • EDA: Exploración de los datos de clasificación ECO.
  • Arquitectura BiLSTM-CNN-ATT: Implementación y entrenamiento de una red neuronal con atención.
  • Modelo Transformers: Uso de modelos tipo Transformer (BETO) para clasificación.
  • LLM Generativo Zephyr-7B: Aplicación de un modelo generativo a la tarea.
